# BTV Releases
Officiële Android TV releases voor **BTV**.

## Installatie via Downloader
1. Open de **Downloader** app op je Android TV of mediaspeler.
2. Voer de nieuwste Downloader shortlink in (zie hieronder bij de nieuwste release).
3. Installeer de APK en start BTV.

## In-App Updates
Zodra BTV geïnstalleerd is, ontvang je updates automatisch via de ingebouwde update-checker:
- Ga naar **Instellingen** (tandwieltje) > **Over BTV** > **Zoeken naar updates**.
